I deleted a file. What now?

A calm, step-by-step guide to getting photos, videos and documents back. Free. No sign-up. This page collects nothing: everything runs in your browser.

First, the one rule that matters

Stop using the device now. A deleted file is usually still there until new data is written over it. Do not take new photos, install apps, copy files onto the same drive, or "clean up". Every new write lowers the chance of getting your file back.

Also: never save recovered files onto the same drive you are recovering from.

1. Where were the files?

Android phone: try the easy places first

  1. Gallery / Google Photos trash. Open the app, then Library → Bin / Trash. Deleted items stay about 30-60 days. Select and tap Restore.
  2. Files app trash. Many phones keep a Recycle bin (Files → menu → Recycle bin).
  3. Hidden trash files. Android 11+ renames deleted files to .trashed-... for about 30 days. File Rescue can find these, plus WhatsApp statuses and thumbnails, even if the app trash was emptied.
  4. Not found? If the photos were on an SD card, take the card out and follow the .

To use File Rescue on the phone itself, install the free Android app from the Releases page. It needs no internet permission.

·

SD card or pen drive: you need a computer

  1. Remove the card from the phone/camera right away and do not put it back.
  2. Plug it into a computer with a card reader or USB adapter. If Windows asks to "format" it, click Cancel.
  3. Download File Rescue (free, open source) from the Releases page. On Windows, take FileRescue-gui.exe: no install, no command line.
  4. Open it, choose the card, tick Photos / Videos and press Scan. Pick a folder on your computer (not on the card) for the results.
  5. If the card is FAT32 or exFAT, use Undelete first: the "Undelete" mode brings files back with their original names and folders. If names are gone or the card was formatted, use the Deep scan: it finds files by their content, without names.

Tip Big card? A deep scan can take hours. It saves progress, so on the command line you can stop (Ctrl+C) and continue later with --resume.

·

Windows computer

  1. Check the Recycle Bin first. Right-click a file → Restore. File Rescue can also restore from the Recycle Bin for you.
  2. Check backups: File History, OneDrive/Google Drive trash, or "Previous versions" (right-click the folder → Properties).
  3. If the files were on the C: drive, stop using the computer as much as possible. Better still, shut it down and connect the drive to another computer, or run File Rescue from a pen drive.
  4. Run FileRescue-gui.exe from a different drive than the one you are scanning. Choose the drive, press Scan, save results on another drive.
  5. NTFS drives support Undelete (names and folders kept). SSDs often erase deleted data quickly (TRIM), so results can be limited.

·

Linux, or a Linux/Android SD card (ext2/3/4)

  1. Unmount the drive so nothing writes to it: 
    sudo umount /dev/sdX1
  2. Install File Rescue: 
    pip install git+https://github.com/Bhushansavande/file-rescue.git
  3. Try undelete with names (works while the file system journal still holds the old entries): 
    sudo filerescue undelete /dev/sdX1 -o ~/recovered
  4. If that finds nothing, run the content-based deep scan: 
    sudo filerescue carve /dev/sdX1 -o ~/recovered --types photos,videos

Honest note On ext4, deleting wipes the file's block list. File Rescue rebuilds it from the journal, which only keeps recent history, so act quickly.

·

After recovery: check your files

  1. Open the report.html that File Rescue writes in the results folder. It shows thumbnails and sizes.
  2. Files marked suspect or partial are probably damaged (for example, half of a photo was overwritten). Look at those first and do not expect all of them to open.
  3. Copy the files you want to a safe place, and make a second backup (cloud or another drive).
  4. Only then use the old drive normally again.

Things that do not work (so you do not waste time)

  • Files overwritten by newer data cannot be recovered by any software.
  • Most modern phones encrypt internal storage: a deep scan of the internal memory is not possible without root. The trash and thumbnail methods above are the realistic options.
  • Be careful with "recover everything" apps that ask for payment first. File Rescue is free and open source (MIT).
