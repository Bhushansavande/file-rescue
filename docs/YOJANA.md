# प्रोजेक्ट योजना (Roadmap)

## उद्देश

सामान्य माणसाला मराठीतून समजेल अशा पद्धतीने, **मोफत आणि ओपन-सोर्स** साधनांनी डिलीट झालेले फोटो, व्हिडिओ, गाणी आणि APK परत मिळवण्यास मदत करणे, आणि कुठे शक्य नाही हे प्रामाणिकपणे सांगणे.

## सध्याची स्थिती: v0.1 ✅

- [x] File carving: JPG, PNG, GIF, WEBP, MP4/MOV/3GP/M4A, MP3, WAV, AVI, PDF, ZIP, APK, DOCX/XLSX/PPTX
- [x] अचूक लांबी मोजणे (JPEG मार्कर्स, MP4 बॉक्सेस, MP3 फ्रेम्स, ZIP/EOCD)
- [x] Windows Recycle Bin रिस्टोअर (मूळ नावासह)
- [x] Android `.trashed-*` / ट्रॅश फाइल्स ADB द्वारे
- [x] सुरक्षित इमेज प्रत (`image`)
- [x] मराठी README आणि शिक्षण
- [x] ऑटोमेटेड टेस्ट्स

## टप्पा 2: v0.2 (उपयोगिता)

- [ ] **GUI** (Tkinter किंवा Flutter Desktop): ड्राइव्ह निवडा, प्रकार निवडा, बटण दाबा
- [ ] फाइल्सचे **थंबनेल पूर्वावलोकन**, निवडक फाइल्स सेव्ह करणे
- [ ] ड्राइव्हची यादी स्वयंचलित दाखवणे (Windows/Linux)
- [ ] प्रगती, वेळ-अंदाज, थांबवा/पुन्हा सुरू करा
- [ ] इंग्रजी + मराठी भाषा निवड

## टप्पा 3: v0.3 (अधिक प्रकार)

- [ ] MP3 (ID3 शिवाय), AAC, FLAC, OGG, OPUS (WhatsApp ऑडिओ)
- [ ] HEIC/HEIF (iPhone), RAW (CR2/NEF/ARW), BMP, TIFF
- [ ] MKV, WEBM, FLV; Office जुने प्रकार (DOC/XLS)
- [ ] SQLite (WhatsApp डेटाबेस `msgstore.db`)
- [ ] **डुप्लिकेट काढणे** (hash द्वारे), तारीख वाचून EXIF/ID3 नुसार फाइलचे नाव देणे

## टप्पा 4: v0.4 (फाइल सिस्टम)

- [ ] FAT32/exFAT डिरेक्टरी एंट्रीज वाचून **मूळ नावासह** रिकव्हरी
- [ ] NTFS MFT वाचन (नावे, तारखा)
- [ ] तुकड्या-तुकड्यात (fragmented) फाइल्ससाठी सोपी हेरिस्टिक्स

## टप्पा 5: Android सुधारणा

- [ ] Flutter ॲप: फोनवरच ट्रॅश फोल्डर्स आणि बॅकअप स्कॅन (Storage Access Framework द्वारे)
- [ ] Google Photos / WhatsApp बॅकअप तपासणीसाठी मार्गदर्शक विझार्ड
- [ ] SD कार्ड carving मार्गदर्शन व्हिडिओ

## तांत्रिक निर्णय

| निर्णय | कारण |
|---|---|
| Python, शून्य बाहेरील लायब्ररी | सोपे इन्स्टॉल, शिकायला सोपे, पोर्टेबल |
| फक्त वाचन (read-only) | स्रोत डेटा सुरक्षित राहतो |
| 512 बाइट्स alignment | खोटे हिट्स कमी, वेग जास्त |
| ओपन-सोर्स (MIT) | कोणीही वापरू/सुधारू शकतो |

## गुणवत्ता नियम

- प्रत्येक नवीन फाइल प्रकारासोबत एक टेस्ट (कृत्रिम इमेजमध्ये अचूक hash जुळला पाहिजे).
- खोट्या हिट्ससाठी कठोर validator; शंका असल्यास फाइल घेऊ नका.
- README मध्ये मर्यादा नेहमी प्रामाणिकपणे सांगा.
