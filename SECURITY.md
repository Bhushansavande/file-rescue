# Security Policy

File Rescue only reads from the devices you point it at and never writes to them.

If you find a security problem (for example a crafted disk image that makes the tool crash or write outside the output folder), please report it privately through GitHub's **Security → Report a vulnerability** on this repository instead of opening a public issue.

Recovered files, especially APKs and documents, come from untrusted data. Inspect them before opening or installing them.
